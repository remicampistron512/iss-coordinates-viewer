# iss-coordinates-viewer
Un programme Python (en mode console) qui exploite les APIs mises à disposition sur http://open-notify.org/ 
pour afficher la position (latitude et longitude) horodatée de la station spatiale internationale, le nombre de ses 
occupants et leur nom.


# Installation et exécution

1. Créer l'environnement virtuel :

   ```bash
   python -m venv .venv
    ```

2. Activer l'environnement virtuel :

   **Windows**

   ```bash
   .venv\Scripts\activate
   ```

   **Linux / macOS**

   ```bash
   source .venv/bin/activate
   ```

3. Installer les dépendances :

   ```bash
   pip install -r requirements.txt
   ```

4. Exécuter le programme :

   ```bash
   python main.py
   ```
